# Notes for working in this repo

- Text source of truth is the Google Drive kit (NFH 2025 folder), mirrored into `content/content.json` by `npm run pull`. Image paths and framing are in `content/layout.json`. The data block in `src/page.html` is generated by `scripts/content/write-page.js`; never hand-edit it or `site/index.html`.
- Run `npm run pull` before changing anything, so local text matches Drive. A text fix should be made in Drive, not in content.json, or the next sync overwrites it.
- After any change, run `npm run release` (build + PDF + smoke test) and commit `content/`, `src/page.html`, `site/index.html` and any changed images together. The PDF is built at publish time and not committed; the Publish workflow keeps it matched to the site.
- Kit fields and limits live in `scripts/content/spec.js`. After changing it, `npm run kit` and `npm run test:kit`.
- `src/page.html` is also published as a Claude artifact (https://claude.ai/artifact/Dts97zw9KGjPXs9KodiHWD). Keep it free of `<html>`/`<head>`, and keep the Download PDF code working in both places: it uses the artifact `downloads` capability inside Claude and a plain file link on the website.
- Design: forest green / sage / cream, League Spartan for display, Literata for body. Restraint is preferred: no novelty motifs (filmstrips, tickets, stamps). Marker-style highlights and dark rounded panels are in use and liked.
- Copy: understated and direct. No em dashes.
- Official contact email: info@nonfictionhotlist.com. Project contacts belong to the filmmakers.
- Deploys: `.github/workflows/publish.yml` runs on push to `main`, every 15 minutes (Drive edits) and on demand; it publishes `site/` to `gh-pages` (custom domain nfh2025.rdgnbl.com).
- Project news, laurels and status are edited in each project's sheet in Drive. When adding researched items there, every item needs a source; never add a laurel or award that a source doesn't confirm. `research/` is the October 2026 archive.
- Team dashboard: `site/dashboard/` (unlisted, built by `npm run dashboard`, never committed). GoatCounter counts visits on the website only, through `window.nfhTrack` in `scripts/build-site.js`; the Claude version must not count. Stats need the `GOATCOUNTER_TOKEN` repo secret.
