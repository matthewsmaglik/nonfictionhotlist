# nfh2025.rdgnbl.com

Sends every old link to the 2025 Hotlist's new home, keeping the page:
`nfh2025.rdgnbl.com/#vestibule` → `list.nonfictionhotlist.com/2025/#vestibule`,
`/dashboard/` → `/2025/dashboard/`, `/hotlist-2025.pdf` → `/2025/hotlist-2025.pdf`.

Published from the old repo, `matthewsmaglik/nonfictionhotlist`, once the new site is live: its
publish workflow is disabled and its `gh-pages` branch is replaced with these files (keep the CNAME).
The rdgnbl.com DNS record stays as it is.
